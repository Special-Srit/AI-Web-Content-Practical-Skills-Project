# 와이어프레임 내보내기 (2026-08-05)

피그마 파일 `Concept`에서 내보낸 사본. **원본은 피그마이고 이 폴더는 사본이다.**
구조를 고칠 때는 피그마를 고치고 여기를 다시 내보낸다.

| 파일 | 용도 |
| --- | --- |
| `*.svg` × 11 | 발표자료용 · 벡터라 확대해도 안 깨짐 |
| `node-tree.json` | 구조 백업 — 레이어 이름 · 오토레이아웃 · 좌표 · 텍스트 전부 |

- SVG는 **레이어 이름과 오토레이아웃을 잃는다.** 그래서 `node-tree.json`을 함께 둔다.
  피그마 파일이 사라져도 이 JSON이면 구조를 그대로 다시 세울 수 있다
- 화면 목록은 `docs/04-design.md` §6이 원본이다

## 발표자료에 쓸 때

3-2가 산출물을 전부 PPT에 넣으라고 했으므로 이 SVG를 그대로 쓰면 된다.
**단 이것은 와이어프레임이지 디자인이 아니다** — 3-3에서 강사가 반복해 강조한 구분이다.
색·서체·아이콘이 없는 것은 미완성이 아니라 이 단계의 정의다.
