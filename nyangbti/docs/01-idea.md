# 01. 주제 — 냥BTI

작성일 2026-08-03 · **이 문서는 아이디어 발상 기록이 아니라 주제 출처 기록**

---

## 이 문서가 짧은 이유

- 파이프라인 1단계는 원래 **주제 선정**이지만, 냥BTI는 **발상 과정을 거치지 않음**
- 강사가 자신의 시연 주제(고양이 MBTI)를 **08-03에 과제로 지정**
- 따라서 후보 5개 이상을 발산·수렴하는 통상 절차는 **수행되지 않았고, 수행할 필요도 없었음**
- 그럼에도 이 문서를 두는 이유
  - 02·03 문서가 **아무 근거 없이 시작된 것처럼 보이지 않도록** 출처를 남김
  - 추적성 검사에서 "1단계가 비어 있음"으로 걸리는 것을 방지
  - 발상을 한 척 꾸며 쓰는 것보다 **지정받았다고 적는 것이 정확**

## 서비스 정의

- **냥BTI** — 고양이 성격 유형 검사 웹앱
- 집사가 **자기 고양이**에 대해 문항에 응답 → 성격 유형 분류 → 유형별 처방 제시
- 처방 3종: 추천 놀이 · 추천 장난감 · 상호작용 방식
- 대상: 한국어 사용 집사, 모바일 우선

## 과제로서의 위치

| 항목 | 내용 |
| --- | --- |
| 주제 출처 | 강사 지정 (본인 선정 아님) |
| 성격 | 기획 파이프라인 **연습** — 메인 과제는 팀 프로젝트 |
| 목적 | **포트폴리오** — 실제 출시 대상 아님 |
| 관계 | 팀 프로젝트가 이 프로젝트의 **순서와 양식을 그대로 따름** → 여기서의 부실이 그대로 전파 |

## 웹앱 요건 충족 여부

- 강사가 제시한 웹앱 기준 형태 = **등록 → 검색 → 결과**
- 냥BTI 대응 — 고양이 정보·응답 입력 → 유형 판정 → 결과·처방 열람
- 설치 없이 브라우저에서 동작, 사용자가 기능을 능동적으로 사용 → **브로슈어 사이트 아님**
- 판정: 과정 요건 충족

## 제약 (이후 모든 단계에 적용)

- 순수 **HTML · CSS · JavaScript** — 리액트·뷰·빌드 스텝 없음
- **백엔드 없음** — 서버·DB·인증 불가 → 정적 데이터 + localStorage로 해결
- 가용 기간 약 7.5일, 2인 1조
- 발표 2026-08-14

## 주제 선정을 직접 한 경우와의 차이 — 발표 시 유의

- 강사는 AI 주제 추천이 **본인 사용 패턴에 편향**된다고 경고 → 직접 조사 필요성을 강조
- 이 프로젝트는 주제가 지정되었으므로 **그 편향 문제를 겪지 않았음**
- 대신 시장 검증은 02 문서에서 수행 — 지정된 주제가 실제로 빈 시장인지 사후 확인한 구조
- 팀 프로젝트에서는 주제를 직접 정하므로 **이 단계를 제대로 수행해야 함**
