# 02. 시장조사 · 경쟁사 분석 — 냥BTI

조사일 2026-08-03 · 모든 행은 실제 접속 확인 후 등재 · 미확인 수치는 `미확인` 표기
조사와 검증을 **두 담당이 독립 수행 후 대조** — 뒤집힌 항목은 「교차 검증 결과」 참조

## 이 프로젝트의 성격 — 출시가 아니라 포트폴리오

- 냥BTI는 **실제 서비스 출시 대상이 아님** — 포트폴리오용 결과물
- 따라서 판단 기준이 "시장에서 이길 수 있는가"가 아니라
  **"심사자·면접관이 기억하고 인정할 결과물인가"**
- 이 문서의 시장조사는 그대로 유효 — 수업 필수 단계이고, 근거 없는 기획은
  포트폴리오에서 가장 먼저 지적당함
- 다만 우선순위가 바뀜
  - 중요도 ↓ — 선점 속도, CBTI 출시 경쟁, 사용자 확보, 수익 모델
  - 중요도 ↑ — 과정의 논리적 일관성, 근거 추적 가능성, 완성도, 눈에 보이는 완결성
- **경쟁사 조작·환각은 치명적** — 심사자가 직접 검색해볼 수 있음 (검증 실패 섹션 참조)

## 조사 범위

- 대상 주제: 집사가 **자기 고양이**를 문진 → 성격 유형 분류 → 놀이·장난감·상호작용 처방
- 세그먼트 4개 + 학술 프레임워크 1건, 각각 분리 조사 (통합 금지)
  - A. 고양이·반려묘 성격 검사 — 직접 경쟁
  - B. 반려묘 관리 앱 — 사용자를 이미 보유한 인접 시장
  - C. MBTI형 심리테스트 플랫폼 — 포맷·공유 UX 벤치마크
  - D. 국제 고양이 성격 서비스
  - E. 학술 근거 모델 존재 여부
- 국내 우선 조사, 국제는 한국 사용자에게 유의미한 경우만 등재
- 검증 등급: `스토어 등재` / `공식 사이트` / `언론 보도` / `학술 논문`

**세그먼트 A 요약 (개조식)**

- 한국어 + 우리 고양이 대상 + 실행 처방 — 3요소 동시 충족은 **PetMBTI 단독**, 그마저 완성도 낮음
- 국내 접근성 높은 테스트 다수가 **집사 본인 대상** (푸망·BLTI·포캣멍센터)
- 근거 기반 서비스(IDRLabs)는 한국어 미지원 + 권고 명시적 거부
- 대중형(PurrJung)은 한국어 되나 처방 없음 + 번역체
- 카테고리 최강자 DBTI는 개 전용, 고양이 판 미출시

- 공유 버튼은 결과 화면 최상단 근접 배치

## D. 국제 서비스

## E. 학술 근거 모델 — 실존 확인

- **Feline Five** — 실존하는 동료 심사 논문, 신뢰도 자산으로 사용 가능
- 서지: Litchfield CA, Quinton G, Tindle H, Chiera B, Kikillus KH, Roetman P. (2017). *The 'Feline Five': An exploration of personality in pet cats (Felis catus)*. **PLOS ONE 12(8): e0183455**, 2017-08-23, DOI 10.1371/journal.pone.0183455
- 라이선스 **CC-BY 4.0** — 출처 표기하면 인용·재사용 자유
- 표본: 반려묘 2,802마리 (남호주 1,687 / 뉴질랜드 1,115), 보호자 평정 52개 문항 → 요인분석 후 48개, 7점 리커트
- 5요인 (논문 표현 + Table 3 신뢰도 α)
  - **Neuroticism** 신경성 (.90) — insecure, anxious, fearful of people, suspicious, shy
  - **Extraversion** 외향성 (.80) — active, curious, inquisitive, inventive
  - **Dominance** 우월성 (.80) — bullying, dominant, aggressive to other cats
  - **Impulsiveness** 충동성 (.72) — impulsive, erratic, reckless
  - **Agreeableness** 친화성 (.78) — affectionate, friendly to people, gentle

### 논문 인용 시 반드시 지킬 두 가지 — 교차 검증에서 확인

- 이 논문은 스스로를 **탐색적 연구(exploratory study)** 로 규정 — **검증된 측정도구 아님**
  - 따라서 "과학적으로 검증된 모델" 이라고 쓰면 **원문과 배치되는 허위 진술**
  - 참고: **PurrJung이 실제로 이 과장을 하고 있음** — 우리는 반대로 가는 것이 차별점
  - 정확한 표현: "탐색적 연구에서 도출된 5요인을 참고해 문항을 설계"
- 5요인은 **연속적 차원 점수**, 이분 축(axis) 아님
  - 그래서 "Feline Five 기반 16유형" 은 **성립하지 않는 문장**
  - 정직한 표현: 문항은 논문을 참고, 결과 유형화는 재미를 위한 단순화

### 고양이 성격 모델은 요인 개수 합의가 없음 — 오히려 유리한 근거

- Bennett, Rutter, Woodhead, Howell (2017). *Behavioural Processes* 141(3):273–283 — **6차원** (Playfulness · Nervousness · Amiability · Dominance · Demandingness · Gullibility), 보호자 416명
- Ha & Ha (2017). *Behavioural Processes* 141(3):351–356 — 초록은 "six significant dimensions" 라고 하면서 **다섯 개만 열거** (원문 자체 불일치)
- 시사점: 학계도 요인 수가 5/6으로 갈림 → **특정 논문 축을 그대로 못 쓰는 것이 흠이 아님**
  - 발표 논리: "모델 간 합의가 없으므로 참고만 하고 형식은 MBTI를 차용" 이 방어 가능
- 논문이 직접 제시한 보호자 실천 권고 = 처방 근거로 그대로 인용 가능
  - 신경성 높음 → 은신처 추가 제공
  - 외향성 높음 → 환경 풍부화(enrichment) 강화
  - 충동성 높음 → 환경 스트레스 요인 점검
  - 친화성 낮음 → 통증·질환 가능성 확인
  - 우월성 높음 → 다묘 가정 자원 분리·갈등 관리
- 시사점: **처방을 지어내지 않아도 논문 권고를 근거로 제시 가능** — 국내 경쟁사 중 이를 한국어로 하는 곳 없음
- 원본 Cat Tracker 연구도 참여 보호자에게 **개인화된 성격 리포트를 돌려줌** — 검사 → 리포트 흐름 자체가 연구에서 검증된 UX
- 주의: MBTI 4축과 Feline Five 5요인은 **다른 체계** — 4축 16유형과 5요인 점수는 서로 환산되지 않음
  - "MBTI 형식을 빌린 재미"와 "논문 근거"는 문구를 분리해 표기
  - 논문을 근거로 내세우면서 유형 체계는 MBTI를 따르는 것이 가장 흔한 지적 대상 → 차별화 1번 항목 참조

## 부족한 영역 (Gap)

- **한국어 × 우리 고양이 대상 × 실행 가능한 처방** — 3요소 동시 충족 서비스 사실상 부재
- 국내 유통 중인 고양이 테스트 상당수가 **집사 본인 성격 측정** (푸망·BLTI·포캣멍센터)
- 근거 기반 검사(IDRLabs)는 **한국어 없음 + 권고 제공 거부** 명시
- 대중형(PurrJung)은 한국어 로케일(`/ko`) 보유 — 다만 **장난감·놀이 처방 없음**
  - 대신 **"과학적으로 검증된 모델" 이라 과장** → 원논문은 탐색적 연구, 정확성으로 앞설 여지
- 관리 앱 전부 **성향·관계 이해 기능 0** — 기록만 하고 해석은 안 함
- **앱 스토어에 고양이 성격 검사 앱이 없음** — Google Play(KR) `고양이 성격 테스트` 검색 결과 12개 전부 사람용 범용 MBTI 앱
  - 경쟁이 **웹에만 존재** = 웹앱으로 만드는 이 과정의 제약과 정확히 맞음
- 카테고리 1등 DBTI가 **CBTI(고양이 판) 준비 중**이라 공식 표명
  - 실제 출시 프로젝트라면 시한부 공백 — **포트폴리오이므로 경쟁 압박은 무의미**
  - 발표에서는 "1등이 같은 공백을 노린다고 공표한 상태" = 시장 판단이 맞았다는 근거로 사용
- **"하지 말아야 할 것" 안내 서비스 전무** — 처방은 전부 권장 목록뿐
- 다묘 가정의 **고양이 간 성향 비교**를 다루는 국내 서비스 없음 (PurrJung만 궁합 제공, 한국어 품질 낮음)

## 차별화 포인트 — 7.5일 · 백엔드 없음 기준

**포트폴리오 기준 재정렬** — 심사자에게 보이는 값이 큰 순서

1. 금지 목록 (3번) — 어디에도 없는 발상, 한 줄로 설명되는 차별점
2. 논문 근거 + 탐색적 연구·축 불일치 명시 (1번) — 한계를 알고 설계했다는 증거
   - PurrJung이 "검증된 모델"로 과장하는 지점을 우리는 정확히 쓰는 것 자체가 차별점
3. 결과 카드 이미지 생성 (4번) — 눈에 보이는 완성도
4. 유형별 정적 결과 페이지 · og:image (5번) — 1등 패턴을 백엔드 없이 재현한 기술적 판단
   (신규 발상은 아님, 5번 항목 정정 참조)
5. 나머지는 기본기 항목

**채택 (구현 가능)**

1. **논문 근거 명시** — Feline Five(PLOS ONE 2017) 인용
   - 국내 유일 "근거 밝힌 한국어 고양이 성격 검사" 포지션
   - 구현 비용 = 문구·출처 표기뿐, 코드 부담 0
   - **미결 쟁점: 축 개수 불일치** — 논문은 5요인, MBTI 형식은 4축 16유형
     - 4축을 5요인에 억지로 매핑하면 근거가 무너짐 → 검증 단계에서 지적받을 지점
     - 선택 A: 4축 16유형 유지 + "문항을 Feline Five에서 참고" 수준으로만 표기 (정직)
     - 선택 B: 5요인 점수제 채택 + 16유형 포기 (논문 충실, 바이럴 약화)
     - **포트폴리오 기준으로는 선택 A + 한계 명시가 유리** — 강사 예제(고양이 MBTI)
       형식을 지키면서, 축 불일치를 알고 감수했다고 문서에 남기는 편이
       "논문 기반"이라고 뭉개는 것보다 평가에서 강함
2. **결과 = 처방** — 유형별 `추천 놀이 / 추천 장난감 / 상호작용 방식` 3블록 고정
   - 정적 JSON 데이터로 전량 사전 작성, 백엔드 불필요
   - PetMBTI가 하지만 산만함 → 냥BTI는 이것만 깔끔하게
3. **금지 목록 — "이 아이한테 하지 마세요"** — 유형별 역권고 2~3개
   - 전 경쟁사 미제공, 체감 효용 가장 큰 차별점
   - 예: 신경성 높은 유형에게 갑작스러운 안기·큰 소리
4. **결과 카드 이미지 생성** — Canvas로 세로 카드 렌더 → 저장/공유
   - `canvas.toBlob()` + Web Share API, 순수 클라이언트
5. **유형별 정적 결과 페이지 16개** — `/result/xxxx.html` 각각 고유 `og:image`
   - 카카오톡·SNS 링크 미리보기가 유형별로 다르게 뜸
   - 답변은 쿼리스트링으로 전달, 서버 저장 불필요
   - **정정: 신규 발상 아님** — 푸망이 이미 결과별 URL(`/t/{slug}/result/{id}?c={type}`)에
     유형별 OG title·description·image를 붙여 운영 중 (교차 검증에서 확인)
   - 따라서 "차별점"이 아니라 **1등 플랫폼 패턴을 백엔드 없이 정적으로 재현한 것**
     - 이 표현이 정확 — 벤치마킹했다고 밝히는 편이 평가에서 유리
6. **다묘 비교** — localStorage에 여러 마리 결과 저장 → 성향 차이 나란히 표시
   - 국내 미제공 기능, 저장소만으로 구현
7. **관찰형 문항** — "지금 기억나는 행동"이 아니라 "최근 일주일 관찰"로 문항 프레이밍
   - 정확도 서사 확보, 비용 0
8. **모바일 우선 · 1문항 1화면 · 회원가입 없음** — DBTI/PurrJung 공통 성공 조건 답습

**범위 외 (백엔드·인증·실시간 필요 — 계획에 넣지 말 것)**

- 참여자 수 카운터 / 유형별 분포 통계 → 서버 DB 필요
- 계정 로그인·기기 간 결과 동기화 → 인증 필요
- 같은 유형 집사 커뮤니티 (DBTI 보유 기능) → 서버 + 운영 필요
- 사진 기반 AI 성향 분석 → 모델·추론 서버 필요
- 재검사 추이 추적 서버 저장 → localStorage로 부분 대체만 가능
- 카카오 JavaScript SDK 공유 → 앱 등록·도메인 등록 필요, **조건부** (배포 도메인 확정 후 여유 있으면, 없으면 링크 복사 + 이미지 저장으로 대체)

## 포지셔닝

반려묘 시장은 지금 두 갈래로만 갈라져 있다. 한쪽에는 티티케어·똑똑집사·고양이 연구소 같은 관리 앱이 있어 무엇을 먹였고 언제 아팠는지를 성실히 기록하지만, 그 고양이가 어떤 아이인지는 끝내 말해주지 않는다. 다른 한쪽에는 푸망과 스모어의 고양이 테스트가 있지만 정작 측정 대상이 집사 자신이고, 우리 고양이를 실제로 재는 PurrJung과 IDRLabs는 각각 처방이 없거나 한국어가 없다. 강아지 쪽에서 이 자리를 정확히 채운 DBTI는 스스로 "고양이는 별도 프레임워크가 필요하다"며 CBTI를 준비 중이라 밝혔을 뿐 아직 내놓지 않았다. 냥BTI가 설 자리는 바로 그 공백이다 — 일반론으로 "고양이란 이런 동물"을 설명하는 대신 Feline Five라는 실재하는 탐색적 연구를 참고해 **우리 집 이 고양이 한 마리**의 성향을 읽어내고, 그에 맞는 놀이와 장난감과 다가가는 방식, 그리고 아무도 알려주지 않던 "하지 말아야 할 것"까지 한국어로 건네는 것. 시장은 관리에 몰려 있고, 비어 있는 것은 관계 이해다.
