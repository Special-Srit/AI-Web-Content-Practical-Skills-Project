## 전역 규칙 요약 (Rev 7)

- 16:9 · 좌여백 `LX = 0.50"` · 콘텐츠 폭 `W = 9.00"`
- 앵커 — 챕터라벨 `0.28"` / 제목 `0.60"` / 부제 `1.15"` / 콘텐츠 `1.68"` / **상한 `5.08"`** / 푸터 `5.28"`
- 페이지 번호 **2자리 영패딩** (`01`), 표지·마지막 장은 번호 없음
- 반복 타일은 **등폭 공식** `itemW = (W − (N−1) × gap) / N`
- **이모지 금지** — 위계는 색(링크 블루)·굵기(SemiBold)·구분선으로만
- 폰트는 **Paperlogy Filled** 계열 (스톡 Paperlogy 아님 — 한글 조합 미지원)

# 11 · 페르소나의 성격 — 먼저 밝힐 것

**[타입]** `slide-content`

- 챕터 라벨: `04 · 페르소나`
- 제목: **프로토 페르소나입니다**
- 부제: `사용자 인터뷰·설문 없이, 경쟁사 분석과 추론으로 만든 가설`

| 항목 | 내용 |
| --- | --- |
| 유형 | 프로토 페르소나 (proto-persona) — NN/g가 인정하는 3유형 중 하나 |
| 근거 | 경쟁사 18행 + 논문 3편 + 검증 실패 13건 |
| 용도 | **설계 초점 도구 — 데이터로 주장하지 않음** |
| 검증 계획 | 실제 집사 5명 롤링 인터뷰 |

- 가장 약한 가정 — **"집사가 자기 고양이 행동을 문항으로 답할 만큼 관찰하고 있다"**
  - 틀리면 검사 구조 전체가 무너짐 → 대응으로 **"모르겠음" 선택지**와 관찰형 문항 도입

# 13–15 · 페르소나 A / B / C (3장)

**공통 구조**

- 퇴근 후 계속 붙어 있음 — 하악질 한 번에 겁먹고 접촉을 줄임
- 동기: `우리 고양이 행동을 하나도 해석 못 하겠음`
- 니즈: `이 행동이 무슨 뜻인지 알고 싶음`
- TO-BE: `유형을 알고 나서 접촉 강도를 조절, 하지 말아야 할 행동을 구분`
- 필요 기능: 유형 서사 · **금지 목록** · "모르겠음" 선택지

**14 · B — 문서연 (맞벌이 집사) · supplemental**

- 평일 10시간 이상 부재 · 밤 20~30분 몰아치기 놀이 · 월 20~30만원대

- 니즈: `실패 없이 딱 하나만 정확히 사고 싶음`
- TO-BE: `유형별 장난감 우선순위 1종을 확인하고 구매`
- 필요 기능: 처방 3블록 · 우선순위 1종 표기 · 배우자 공유 링크

**15 · C — 임현석 (다묘가정 집사) · secondary**

- 니즈: `세 마리 성향을 나란히 비교해 보고 싶음`
- TO-BE: `유형 조합을 근거로 자원 분리와 배분을 조정`
- 필요 기능: **다묘 비교(localStorage)** · 유형 조합별 자원 분리 권고

# 16 · 주 페르소나 지정

**[타입]** `slide-flow-steps` — 3단, `boxW = (9.00 − 2 × 0.12) / 3 = 2.92"`

| 단계 | 라벨 | 설명 |
| --- | --- | --- |
| 01 | B를 타깃하면 | 문항 최소 + 장난감 한 장으로 수렴 → **A는 입력조차 못 함** |
| 02 | C를 타깃하면 | 비교 화면이 "한 마리를 읽을 줄 안다"를 전제 → **A는 진입 과부하** |
| 03 | A를 타깃하면 | B는 처방·짧은 소요로 최소 만족, C는 비교 화면 하나 추가로 만족 |

하단 결론 (SemiBold, `{colors.link}`):

- C = secondary — 다묘 비교 1개만, **첫 화면 노출 금지**
- B = supplemental — 설계를 바꾸지 않음. B 전용 기능 추가하지 않음

▶ 스크립트: "세 명을 다 만족시키겠다는 건 방법론적으로 틀린 답이라고 배웠습니다. 하나를 정해야 하고, 기준은 '이 사람 기준으로 만들면 나머지도 최소한 불만은 없는가'입니다. 소거해 보면 A가 남습니다. 가장 만족시키기 어려운 사람이기도 합니다."
