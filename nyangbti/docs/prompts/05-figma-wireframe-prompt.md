# 05. Figma 와이어프레임 프롬프트 (Codex 실행용)

실행 방법 — Figma 데스크톱 앱을 먼저 열고 대상 파일을 띄운 뒤, 터미널에서 `codex` 를
**포그라운드로** 실행하고 아래 본문을 붙여넣는다. 백그라운드 작업으로 돌리지 말 것:
노드 생성은 한 번에 끝나지 않고 결과를 보면서 이어가야 한다.

주의 — `figma-bridge` 는 Figma 데스크톱과의 연결을 하나만 유지한다. Codex가 작업하는
동안 Claude 측 figma-bridge는 사용하지 않는다.

---

## 프롬프트 본문 (여기서부터 복사)

당신은 UI 구조 설계자입니다. Figma에서 **회색 상자(grey-box) 와이어프레임**만 만듭니다.

### 만들려는 것

`냥BTI` — 고양이 성격 유형 검사 웹앱의 와이어프레임. 8개 화면.

### 앱의 목표

사용자가 자기 고양이를 16문항(약 3분) 관찰형 검사로 판정받고, 결과로 **처방 3블록**
(추천 놀이 / 추천 장난감 / 상호작용 방식)과 **"이 아이한테 하지 마세요" 금지 목록**을
받는다. 회원가입 없음, 서버 없음, localStorage만 사용, 모바일 우선.

### 반드시 먼저 읽을 것

`~/Projects/AI-Web-Content-Practical-Skills-Project/nyangbti/docs/04-design.md` 의 **§6
와이어프레임** 절. 화면별 레이아웃 영역·히어로 내용·주요 액션 위치·내비게이션 위치가
이미 확정되어 있다. **그 명세를 그대로 옮기는 것이 이 작업이고, 새로 설계하는 것이
아니다.** §2의 IA 구조와 §5의 예외·빈 상태도 함께 읽는다.

### 만들 화면 8개 + 컴포넌트 1개

| 프레임 | 화면 | footer |
| --- | --- | --- |
| `S1-start` | 시작 화면 | 없음 |
| `S1a-resume` | 이어하기 분기 (오버레이) | 없음 |
| `S2-question` | 문항 화면 (16단계 동일 템플릿, 1개만 제작) | 없음 |
| `S3-result` | 결과 화면 | 없음 |
| `S3c-save` | 저장 시트 | 없음 |
| `S3d-share` | 공유·카드 시트 | 없음 |
| `T2-records` | 내 기록 | 있음 |
| `T3-compare` | 비교 | 있음 |
| `T4-about` | 알아보기 | 있음 |
| `nav-footer` | 하단 내비게이션 컴포넌트 (검사·내 기록·비교·알아보기) | — |

프레임 크기 — 390×844 (모바일 기준). 하단 내비게이션에는 `env(safe-area-inset-bottom)`
상당의 여백을 아래쪽에 확보하고, 각 탭 히트 영역은 48×48 이상으로 잡는다.

### 절대 하지 말 것 — 이 프로젝트의 규칙

- **색·서체·이미지를 고르지 않는다.** 회색 톤과 기본 폰트만. 시각 디자인은 사용자(스릿)가
  직접 Figma에서 한다. 와이어(철사) + 프레임(틀)까지가 이 작업의 범위다.
- **이미지로 출력하지 않는다.** 반드시 편집 가능한 Figma 노드로 만든다. 강사 예제가 정확히
  이 지점에서 실패했다(이미지로 나와 수정 불가).
- 아이콘을 그리지 않는다. 자리표시 사각형 + 라벨 텍스트로 둔다.
- 앱 코드를 쓰지 않는다.
- `04-design.md` 를 포함해 어떤 파일도 수정하지 않는다. Figma 노드만 만든다.
- git 명령을 실행하지 않는다.

### 만드는 방식

- `create_frame` 으로 화면 프레임을 만들고 `set_auto_layout` 으로 세로 스택을 잡는다.
- 각 영역은 `create_shape` 회색 사각형 + `create_text` 실제 라벨로 표현한다.
  라벨은 `04-design.md` 에 적힌 한국어 문구를 그대로 쓴다 — 임의로 다시 쓰지 않는다.
- 레이어 이름을 위 표의 프레임 이름과 영역 이름으로 정확히 붙인다. 이름이 곧 구조다.
- 화면 하나를 끝낼 때마다 결과를 확인하고 다음으로 넘어간다. 8개를 한 번에 몰아서
  만들지 않는다.

### 먼저 할 일

**`S1-start` 한 화면만 만들고 멈춘다.** 결과를 보고할 것. 스릿이 확인한 뒤에 나머지를
진행한다. 8개를 다 만들어 놓고 방향이 틀리면 전부 다시 해야 한다.
