## 질문

**shadcn/ui와 같은 방식이면서 "모바일 우선"으로 설계된 UI 컴포넌트 라이브러리가 존재하는가?**

"shadcn/ui와 같은 방식"의 정의 (이 4개를 모두 만족해야 유사 사례로 인정):

2. **CSS 변수 기반 테마** — 토큰을 바꿔 전체 룩을 교체
3. **접근성 처리된 프리미티브** 위에 스타일이 얹힌 구조
4. MIT 등 **자유 라이선스**

## 반드시 먼저 읽을 것

`nyangbti/docs/06-design-system.md` — 이 조사가 필요해진 이유가 §3과 §5에 적혀 있다. 요약:

- shadcn/ui 기본 치수가 **데스크톱 밀도**다. Button `default` = `h-9`(36px), 최대인 `lg`도 `h-10`(40px)로 **44px 미달**. Input도 `h-9`
- shadcn/ui에는 **모바일 하단 탭 바 컴포넌트가 없다** (Sidebar만 제공). 우리 IA의 4탭 셸을 직접 만들어야 한다
- 우리 요구치 — 터치 타깃 **44×44 이상**(WCAG 2.1 SC 2.5.5), 하단 탭 **48×48 이상**(Material), 본문 **16px 이상**
