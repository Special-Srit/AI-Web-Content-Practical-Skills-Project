## Top 5 bets

1. 한국장학재단 CSV — 작고 연 1회 갱신되며 키·백엔드 없이 바로 vendoring할 수 있다.
2. 고용24 Open API — 직업계고 학생에게 채용·훈련·직업정보를 한 흐름으로 연결할 수 있다.
3. Papa Parse — 공공 CSV 스냅샷을 브라우저에서 가장 단순하게 읽게 해준다.
4. Fuse.js — 로컬 JSON 검색을 오타 허용 검색으로 개선하면서 서버가 필요 없다.
5. DuckDB-Wasm — 작은 정적 데이터셋을 SQL로 필터·집계해 JavaScript 수작업을 줄여준다.

## Dead/deprecated/paywalled suspects

- 워크넷의 구형 API/LOD 표면은 고용24 전환 공지가 있어 deprecated 가능성이 있다.
