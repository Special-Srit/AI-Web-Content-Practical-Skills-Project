## 차용할 구조 패턴

- **표지 — 굵은 워드마크 + 좌하단 스택 자막.** 큰 산세리프 워드마크("DESIGN") 하나만
  본문 없이 배치하고, 자막(날짜 박스 + 3줄 스택 텍스트)은 왼쪽 하단에 작게. 헤드라인이
  압도적으로 크고 부제는 정보 밀도만 담당 — 이 비율을 그대로 차용
- **섹션 구분 슬라이드 — 단색 다이아몬드 + 사진 배경.** 흑백 사진 위에 원색 다이아몬드
  (사각형을 45도 회전) 도형을 중앙에 얹고 그 위에 흰 글자로 섹션명. 본문 슬라이드와
  뚜렷하게 다른 리듬을 줘서 "여기서 파트가 바뀐다"는 신호를 명확히 함
- **아이콘 클러스터 — 회전된 사각(다이아몬드) 배지 3~5개를 방사형으로 배치.** "우리의
  미션", "우리가 원하는 것" 같은 개념 슬라이드에서 아이콘 배지를 원형이 아니라 다이아몬드
  모양으로, 중심에서 살짝 겹치게 배치. 본문 없이 라벨 1줄 + 아이콘만
- **타임라인 — 세로선 + 원형 노드 + 연도 라벨, 텍스트는 좌우 교차 배치.** 이미지가 아니라
  타이포와 선만으로 구성된 미니멀 타임라인. `python-pptx`로 그대로 그릴 수 있는 수준
  (원 + 직선 + 텍스트 박스) — 팀 소개나 프로젝트 일정(주제 선정 → 코딩 → 발표) 슬라이드에
  차용 가능
- **팀 소개 — 원형 사진 + 이름/역할 캡션, 가로 3분할.** 팀원 3명(Clova)에 정확히
  들어맞는 패턴. 원형 크롭 + 짧은 라벨이라 사진 품질 편차를 감춰 줌
- **데이터 슬라이드 — 표·도넛차트·지도가 각각 독립된 슬라이드.** 여러 데이터 유형을
  한 슬라이드에 욱여넣지 않고 유형별로 분리. §3(경쟁사 표) · §4(페르소나 행동 축 표) ·
  §5(여정 지도)를 나눠서 넣으라는 `14-deck-tooling-research.md` §6 결론과 일치

## 차용하지 않을 것 — 콘텐츠가 안 맞음

- **실물 제품 사진 콜라주(카메라·헤드폰·시계)** — Music Diary는 실물 제품이 없다.
  같은 자리(표지·마지막 장 상단)에 넣을 게 없으므로, 사진 콜라주는 **앱 스크린샷** 또는
  **아이콘 기반 도형 클러스터**로 대체한다(스크린샷은 코딩 완료 후에나 생김 — 그 전까지는
  도형 클러스터로 자리만 잡아둠)
- **흑백 인물/건축 사진 배경(섹션 구분 슬라이드)** — 라이선스 있는 사진을 새로 구해야
  하므로, 사진 대신 **단색 배경 + 도형만**으로 같은 리듬을 낸다(사진 없이도 다이아몬드
  하나만으로 파트 전환 신호는 충분히 남)

## 색상 방향 — 파란색 원색 → Warm Vinyl 톤 치환

레퍼런스는 흰색·검정·그레이스케일 위에 채도 높은 로열블루 하나만 얹는 구조다. 이
구조(무채색 베이스 + 원색 악센트 하나)는 그대로 쓰되, 악센트만 제품명("Warm Vinyl"
테마, `08-concept-music-diary-KR.md` §이름)에 맞춰 바꾼다. 팀 프로젝트는 아직
색상 팔레트가 확정되지 않았으므로(`10-dev-setup.md` §5, 현재 `Neutral` 자리표시),
이 문서가 **덱 전용** 색 제안이다 — 앱 자체의 shadcn 팔레트를 결정하는 문서가 아님.

| 토큰 | 값(안) | 근거 |
| --- | --- | --- |
| CANVAS | `#FBF6EF` (warm ivory) | 레퍼런스의 흰 배경 자리. 바이닐 재킷 종이 질감을 연상시키는 따뜻한 오프화이트 |
| INK | `#241C16` (warm near-black) | 레퍼런스의 검정 텍스트 자리. 바이닐 디스크의 검정을 순수 검정이 아니라 살짝 갈색 기운으로 |
| ACCENT | `#C1502E` (terracotta/rust) | 레퍼런스의 로열블루 자리. 바이닐 라벨 스티커에 흔한 색 계열 — "Warm Vinyl" 이름과 직접 연결 |
| ACCENT_TINT | `#F1DDD2` | 악센트의 옅은 배지·배경용 |
| MUTE | `#8A7A6D` (warm gray) | 레퍼런스의 회색 사진/보조 텍스트 자리 |

**결정하지 않은 것 — 다음 문서에서** 정확한 폰트(냥BTI와 같은 Paperlogy Filled를
그대로 쓸지, 아니면 팀 프로젝트 전용 폰트를 고를지), 도형의 정확한 좌표/반지름,
아이콘 세트(`14-deck-tooling-research.md` §2가 조사한 변환 경로 중 선택).
