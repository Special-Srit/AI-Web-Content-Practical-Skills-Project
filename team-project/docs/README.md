## 04·05·06이 영어로만 있는 이유

**버려진 방향의 조사 자료**다. 스트리밍 서비스 쪽을 보던 시기의 기록이고, 주제가
Music Diary로 정해지면서 결론만 `08`로 넘어갔다. 67,000자를 번역해도 현재 설계에
쓰이지 않으므로 영어로 둔다. **주제 선정 과정을 물으면 이게 근거 자료다** — 빠뜨린
것이 아니라 앞선 단계의 기록이라고 말할 것.

## prompts/

언어로 나누지 않는다. 프롬프트 본문은 **실행한 원문 그대로**(영어)이고, 무엇을 만든
것인지는 `prompts/README.md`의 한국어 표로 따라간다. 3-2 기준 발표 대상 산출물이므로
사후에 손대지 않는다.
